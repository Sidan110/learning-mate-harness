# Learning Mate Harness
느린학습자의 복습을 지원하기 위해 Timely AI 환경에서 구성한 AI 학습 보조 프로젝트입니다. 학습자와의 대화, 수준 진단, 학습 내용 분석, 설명, 퀴즈, 학습 기록 관리를 7개 자동화와 11개 스킬로 나누어 설계했습니다.
## 프로젝트 배경
2026년 여름학기 AI 초급 교육과정에서 진행한 팀 프로젝트입니다. 강원권 대학교 학생들이 참여한 17개 팀 가운데 3위를 수상했습니다.
학습자가 수업 내용을 이해하지 못한 상태에서 다음 내용으로 넘어가거나, 반복되는 실수로 학습 의욕을 잃는 문제에 주목했습니다. 학습 내용을 작은 단계로 나누고, 이해 여부에 따라 설명과 연습을 이어가는 학습 보조 시스템을 목표로 했습니다.
## 프로젝트 개요
- **대상:** 복습과 단계별 설명이 필요한 느린학습자
- **목표:** 학습 부담을 줄이고, 이해 확인과 반복 학습을 지원
- **구현 환경:** Timely AI
- **주요 구성:** 역할별 자동화 7개, 학습 지원 스킬 11개
- **저장소 내용:** 플랫폼에서 사용한 자동화·스킬의 Markdown 정의와 관련 자료
여기서 Harness는 AI가 정해진 역할과 절차에 따라 동작하도록 구성한 운영 구조를 뜻합니다. 이 저장소는 당시 프로젝트의 프롬프트와 역할 설계를 확인할 수 있도록 정리한 포트폴리오입니다.
## 자동화 구성
아래 순서는 당시 플랫폼 화면의 표시 순서입니다. 실제 학습 단계의 실행 순서를 의미하지는 않습니다.
| 자동화 | 설계상 역할 | 파일 |
| --- | --- | --- |
| supervisor-orchestrator | 전체 학습 흐름과 역할 간 연결 관리 | [정의](agents/supervisor-orchestrator.md) |
| rapport-subagent | 편안한 대화와 학습 참여 유도 | [정의](agents/rapport-subagent.md) |

## 스킬 구성
원본 ZIP에 포함된 스킬 11개를 보존했습니다. 각 스킬의 목적, 적용 조건, 처리 방법은 해당 Markdown 문서에 정의되어 있습니다.
자동화는 역할과 흐름을 담당하고, 스킬은 개별 학습 지원 작업에 필요한 지침을 담는 방식으로 구성했습니다.
## 학습 지원 흐름
설계가 지향하는 기본 흐름은 다음과 같습니다.
1. 학습자와 대화하며 복습할 내용과 어려움을 확인합니다.
2. 이해 수준과 필요한 선행 내용을 파악합니다.
3. 학습 내용을 작은 단계로 나누어 설명합니다.
4. 짧은 질문이나 퀴즈로 이해 여부를 확인합니다.
5. 이해가 부족하면 설명과 연습을 보완합니다.
6. 학습 결과를 기록하고 다음 복습으로 연결합니다.
구체적인 분기와 처리 규칙은 자동화 및 스킬 정의를 기준으로 확인할 수 있습니다.
## 자료 확인 및 활용
1. 이 README에서 프로젝트 목적과 역할 구성을 확인합니다.
2. `agents/`에서 자동화별 정의를 읽습니다.
3. 원본 스킬 문서에서 세부 학습 지원 지침을 확인합니다.
4. 실행을 재구성하려면 Timely AI의 자동화·스킬 설정에 문서 내용을 옮기고 역할 간 연결을 설정합니다.
Markdown 파일을 GitHub에 업로드하는 것만으로 플랫폼 자동화가 실행되지는 않습니다. 플랫폼 설정과 실행 환경은 별도로 구성해야 합니다.
## 포트폴리오에서 보여주는 내용
- 학습자의 어려움을 바탕으로 한 문제 정의
- 하나의 학습 과정을 여러 AI 역할로 분리한 설계
- 자동화와 스킬을 활용한 학습 지원 절차 구성
- 설명, 이해 확인, 보완 학습, 진행 관리의 연결
## 향후 개선 방향
- 실제 학습자 피드백을 통한 설명과 질문 난이도 조정
- 역할 간 입력·출력 형식의 명확화
- 학습 기록의 저장 및 조회 기능 보완
- 데모 시나리오와 실행 결과를 통한 동작 검증
- 학습 이해도와 복습 지속성을 확인할 평가 기준 마련
## 자료 범위
이 저장소는 확보한 원본 ZIP의 자동화·스킬 자료를 정리한 것입니다. 포함되지 않은 플랫폼 실행 화면, 데이터, 발표자료 또는 서비스 소스코드를 복원했다고 주장하지 않습니다. 수상 사실과 별개로 실제 학습 효과를 입증한 정량 결과는 이 README에 제시하지 않습니다.
