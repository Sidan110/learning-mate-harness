# Learning Mate Harness
### 느린학습자를 위한 AI 복습 도우미

Timely AI에서 7개 자동화와 11개 스킬을 활용해 설계한 ai 에이전 하네스 학습 보조 프로젝트입니다. 학습자의 이해 수준을 파악하고, 학습 내용을 작은 단계로 나누어 설명하며, 퀴즈와 피드백으로 복습을 지원합니다.

2026년 여름학기 AI 초급 교육과정에서 진행한 팀 프로젝트로, 강원권 대학교 학생들이 참여한 17개 팀 가운데 3위를 수상했습니다.

## 왜 만들었나요?

수업을 따라가는 데 어려움을 겪는 학습자에게는 같은 내용을 반복하는 것뿐 아니라, 어디서 이해가 막혔는지 파악하고 그에 맞게 설명하는 과정이 필요합니다.

이 프로젝트는 학습자가 당일 배운 내용을 자신의 속도로 복습할 수 있도록 돕는 것을 목표로 했습니다.

- 한 번에 많은 내용을 설명하지 않고 작은 단계로 나누기
- 이해가 막히면 필요한 선행 개념부터 다시 설명하기
- 짧은 질문과 퀴즈로 이해 여부 확인하기
- 틀린 답에도 부담을 줄이는 피드백 제공하기
- 학습 결과를 기록하고 다음 복습으로 연결하기

## 어떻게 구현했나요?

Timely AI에서 자동화별 역할과 지침을 정의하고, 세부 학습 지원 작업을 스킬로 나누어 구성했습니다.

전체 흐름을 담당하는 Supervisor와 대화·진단·분석·설명·퀴즈·진행 관리 역할을 분리했습니다. 각 역할이 무엇을 수행하고 다음 단계에 어떤 정보를 전달할지 프롬프트로 정의하는 방식입니다.

| 구성 요소 | 담당 내용 |
| --- | --- |
| Supervisor | 현재 학습 단계와 다음에 수행할 작업 관리 |
| 역할별 자동화 | 진단, 설명, 퀴즈 등 담당 작업 수행 |
| 스킬 | 개별 작업의 처리 방법과 응답 지침 정의 |
| 학습 상태 관리 | 이해 여부에 따라 설명·연습·복습 단계 연결 |

단순히 질문에 답하는 챗봇을 넘어, 학습자의 반응에 따라 다음 학습 과정을 선택하도록 설계했습니다.

## 스킬 11개

| 스킬 | 목적 |
| --- | --- |
| rapport-building | 학습자와 친밀감을 형성하고 대화 시작 |
| lesson-input | 복습할 수업 내용과 학습 범위 확인 |
| level-diagnosis | 현재 이해 수준과 어려운 부분 파악 |
| concept-explanation | 학습 수준에 맞는 개념 설명 |
| lesson-step-analysis | 학습 내용을 작은 단계로 분리 |
| understanding-validation | 설명한 내용을 이해했는지 확인 |
| mini-quiz-generation | 이해 확인을 위한 짧은 퀴즈 생성 |
| non-judgmental-error-handling | 틀린 답에 부담을 줄이는 피드백 제공 |
| prerequisite-decomposition | 필요한 선행 개념으로 나누어 설명 |
| report-generation | 학습 결과와 보완할 내용을 정리 |
| weekly-review | 이전 학습 내용을 돌아보고 복습 지원 |

## 학습 흐름

1. **대화 시작:** 학습자의 상태와 복습할 내용을 확인합니다.
2. **수준 진단:** 이해한 부분과 막힌 부분을 파악합니다.
3. **내용 분석:** 학습 내용을 작은 단계로 나눕니다.
4. **설명:** 필요한 선행 개념부터 수준에 맞춰 설명합니다.
5. **이해 확인:** 짧은 질문이나 퀴즈를 제공합니다.
6. **보완 학습:** 이해가 부족하면 설명과 연습을 보완합니다.
7. **결과 정리:** 학습 결과를 기록하고 다음 복습으로 연결합니다.

## 프로젝트에서 중점적으로 설계한 부분

- **역할 분리:** 각 자동화의 책임을 구분해 학습 과정을 관리
- **단계별 학습:** 내용을 작게 나누고 이해 여부에 따라 진행
- **오답 대응:** 정답 제시와 함께 학습자가 어려워하는 부분을 확인
- **복습 연결:** 한 번의 대화에서 끝나지 않도록 학습 결과를 정리

## 실행 환경

자동화와 스킬은 Timely AI 환경을 기준으로 작성했습니다. 실행하려면 각 정의를 플랫폼에 등록하고 역할 간 연결을 구성해야 합니다.

GitHub에서는 자동화와 스킬의 역할, 지침, 학습 지원 구조를 확인할 수 있습니다.
