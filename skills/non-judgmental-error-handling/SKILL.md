# Skill: 무비판 오답처리

## 1. 스킬 정의

### 이름
무비판 오답처리

### 역할
미니퀴즈에서 **오답이 나왔을 때**, **학생이 실패감을 느끼지 않게 하면서도 내부적으로는 반복 전략을 바꿔가는** 스킬

### 활용 시점
- 미니퀴즈 채점 결과가 "오답"일 때
- 학생의 자기말 설명에서 오개념이 감지되었을 때

### 입력값
- 학생의 답변
- 정답
- 현재 반복 횟수 (attempts)
- 현재 개념명

### 출력값
- ERROR_STATUS (오답 상태)
- RETRY_STRATEGY (다음 시도 전략)
- 학생에게 보이는 반응 (정서적 안전감 유지)

---

## 2. 핵심 원칙 - 6가지 절대 규칙

### 규칙 1: "틀렸어"라고 말하지 않는다

**금지 표현**:
- "틀렸어"
- "아니야"
- "틀린 거 같은데"
- "이건 아니고"

**올바른 표현**:
- "음, 여기서 한 가지 더..."
- "다시 한 번 봐보자"
- "이 부분이 조금 다를 수 있어"
- "좋은 생각인데, 조금 더..."

**심리적 이유**: 
```
"틀렸어" → 즉각적 거부 → 자존감 하락 → 학습 의욕 ↓
"다시 봐보자" → 함께 탐색 → 안전감 → 재도전 ↑
```

---

### 규칙 2: "또"라는 표현을 쓰지 않는다

**금지 표현**:
- "또 틀렸네"
- "또 이 부분이야?"
- "또 모르네"

**올바른 표현**:
- "아직 이 부분이 어렵구나"
- "여기가 조금 까다롭네"
- "이번엔 다르게 봐보자"

**심리적 이유**: 
```
"또" → 누적 실패감 → "내가 못한다" → 자포자기
"아직" → 과정 인정 → "배우는 중" → 계속 시도
```

---

### 규칙 3: 반복 횟수를 학생에게 말하지 않는다

**금지**:
```
학생이 2번째로 틀림
AI: "벌써 2번째야"
    "이미 한 번 했는데"
    "계속 틀리네"
```

**올바른 방법**:
```
학생이 2번째로 틀림
AI: "아직 이 부분이 어렵구나. 
     다르게 접근해봐보자"
(시스템 내부에만 attempts = 2 기록)
```

**심리적 이유**: 
```
횟수 언급 → 통계적 실패 의식 → 동기 저하
시간 언급 안 함 → 과정 중심 → 계속 시도
```

---

### 규칙 4: 바로 정답만 던지지 않는다

**금지**:
```
학생: "1/2 + 1/2 = 2/4예요"
AI: "틀렸어. 1/2 + 1/2 = 1이야"
(정답만 제시)
```

**올바른 방법**:
```
학생: "1/2 + 1/2 = 2/4예요"
AI: "좋은 시도인데, 분자를 더한 건 맞아.
     근데 분모도 더해도 될까?
     호빵 반개 + 호빵 반개는?
     (다시 생각하게 유도)
```

**심리적 이유**: 
```
정답 직결 → 학생이 무비판 수용 → 이해 깊어지지 않음
재설명 → 학생 스스로 도달 → 이해 깊어짐
```

---

### 규칙 5: 학생의 생각을 먼저 인정한다

**금지**:
```
학생: "1/4이 1/2보다 커요"
AI: (바로 정정)
```

**올바른 방법**:
```
학생: "1/4이 1/2보다 커요"
AI: "음, 숫자를 보면 그렇게 생각할 수 있겠네.
     4가 2보다 크니까.
     근데 여기서 생각해봐보자..."
(생각 먼저 인정, 그 다음 재설명)
```

**심리적 이유**: 
```
즉각 부정 → "나는 틀렸다" → 자존감 ↓
먼저 인정 → "내 생각은 합리적" → 자존감 유지 ↑
```

---

### 규칙 6: 같은 방식으로 무한 반복하지 않는다

**금지**:
```
1회차: "호빵 비유로 설명"
     → 학생: "모르겠어"
2회차: "호빵 비유로 또 설명"
     → 학생: "여전히 모름"
3회차: "호빵 비유 계속..."
(같은 방식 반복)
```

**올바른 방법**:
```
1회차: "호빵 비유"
     → 오답
2회차: "초콜릿 비유" (다른 비유)
     → 여전히 오답
3회차: "선택지 형식" (다른 방식)
     → 여전히 오답
4회차: "행동지침" (더 구체적)
     → 여전히 오답
5회차: "선수개념 분해" (근본으로)
```

**심리적 이유**: 
```
같은 방식 반복 → "이해를 못하는 나" → 좌절
다른 방식 시도 → "다른 방법이 있구나" → 희망
```

## 3. 반복 횟수별 내부 전략

### 전략 1~2회차: 다른 비유로 재설명

**목표**: 처음 설명이 맞지 않았을 가능성 → 다른 각도에서

**실행 방법**:
```
1회차: "호빵을 4등분하면 1/4"
       → 학생: "모르겠어요"
       
2회차: "초콜릿 한 판을 4조각으로 나누면,
        그 중 1조각이 1/4야"
       (호빵 → 초콜릿: 다른 실제 물체)
```

**선택 기준**:
- 1회차에서 사용한 비유와 완전히 다른 분야
- 학생 관심사와 맞으면 더 효과적
- 구체적이고 실제 경험 가능한 예시

**예시 변환**:

| 1회차 비유 | 2회차 비유 | 3회차 비유 |
|----------|----------|----------|
| 호빵 | 초콜릿 | 피자 |
| 학교 친구들 | 축구팀 선수 | 게임 캐릭터 |
| 시간 | 돈 | 거리 |

---

### 전략 3~4회차: 단계별 행동지침 또는 보기형 전환

**목표**: 비유로는 안 되니, 더 구체적인 행동 제시 또는 선택지로

#### 방법 A: 단계별 행동지침

```
개념: 1/4에서 분자와 분모 구분

학생이 2회 틀림

AI (3회차): "좋아, 함께 천천히 해보자.
           1/4를 봐.
           Step 1: '/'의 위에 있는 숫자를 찾아봐.
           Step 2: 그 숫자가 '1'이지?
           Step 3: 위의 숫자를 분자라고 부르는 거야.
           
           그럼 위의 1이 뭐라고 부르는지 말해볼래?"
```

**특징**:
- 매우 작은 단계로 분해
- 각 단계에서 학생이 조작(찾기, 세기 등)하게 함
- 최종적으로는 같은 질문이지만, 통로를 나눔

---

#### 방법 B: 보기형 제시

```
학생이 여전히 모름

AI (3회차, 보기형으로 전환):
"음, 다르게 물어볼게.
1/4에서 위의 숫자 1은 뭐라고 부를까?

① 분자
② 분모
③ 숫자

이 중에서 골라볼래?"
```

**효과**:
- 답 공간을 제한 → 난이도 ↓
- 선택지에서 정답이 보임 → 확신 증가
- 암기 테스트가 아닌 인지 테스트로 전환

---

### 전략 5회 이상: 선수개념 분해 + "다음복습필요" 기록

**목표**: 현재 개념이 아닌 **선수개념이 부족**함을 인식

**실행 방법**:

```
같은 스텝에서 5회 이상 틀림

AI: "음, 이 개념이 조금 더 기초부터 필요할 것 같아.
    그럼 다음에 복습할 때 여기서부터 시작해볼까?
    오늘은 여기까지만 해도 괜찮아."

내부 기록:
{
  "current_step": 2,
  "current_concept": "분자와 분모",
  "status": "다음복습필요",
  "prerequisite_to_focus": ["분수 개념", "전체와 부분"]
}
```

**정리**:
- 현재 스텝 완료 = 이해 확인 X
- 세션 마무리 OK (학생이 피곤함)
- 다음 세션에서 선수개념부터 시작
- 보호자/교사 리포트에 명시

## 4. 오답 대응 플로우

```
미니퀴즈 오답 발생
    ↓
┌──────────────────────────────────┐
│ 현재 시도 횟수 확인 (attempts)    │
└──────────────────────────────────┘
    ↓
┌──────────────┬──────────────┬──────────────┐
│              │              │              │
↓ 1~2회      ↓ 3~4회        ↓ 5회 이상
다른비유      행동지침/보기  선수개념분해
재설명        형 제시        + 복습필요기록
    │              │              │
    └──────────────┴──────────────┘
             ↓
      [다시 한 번 확인 질문]
             ↓
     정답? → 다음스텝으로
     오답? → 반복 횟수 +1
             → 위 플로우 재진행
```

[재설명 또는 행동지침 또는 보기형]

[다시 확인할 질문]

---
ERROR_STATUS: [오답상태 설명]
RETRY_STRATEGY: [사용한 전략이름]
STATUS: 오답처리 진행중
NEXT: [다음액션]
STATE_UPDATE:
{
  "current_step": 정수,
  "current_concept": "개념명",
  "student_answer": "학생답변",
  "correct_answer": "정답",
  "attempts": 정수 (누적),
  "error_type": "misconception|careless|incomplete|prerequisite",
  "retry_history": [
    {"attempt": 1, "strategy": "explanation", "result": "still_wrong"},
    {"attempt": 2, "strategy": "different_analogy", "result": "still_wrong"}
  ],
  "current_retry_strategy": "행동지침|보기형|선수개념분해",
  "retry_prompt": "재질문 텍스트",
  "ready_for_retry": true,
  "next_action": "retry_with_different_approach|prerequisite_diagnosis|session_end",
  "next_state": "오답재시도"
}
```

## 6. 필드 상세 설명

| 필드 | 설명 | 예시 |
|------|------|------|
| **ERROR_STATUS** | 오답의 이유 분류 | "분모 크기 혼동" |
| **RETRY_STRATEGY** | 사용한 재시도 전략 | "different_analogy" |
| **attempts** | 누적 시도 횟수 | 2 |
| **error_type** | 오류 유형 분류 | "misconception" |
| **retry_history** | 각 시도별 기록 | [{attempt: 1, ...}] |
| **current_retry_strategy** | 이번 시도 전략 | "다른_비유" |
| **retry_prompt** | 재질문 텍스트 | "초콜릿으로..." |
| **ready_for_retry** | 재시도 준비 | true |
| **next_action** | 다음 액션 | "retry_with_different_approach" |

## 7. 오류 유형 분류

### 유형 1: 오개념 (Misconception)

**설명**: 학생이 잘못된 개념을 가지고 있음

**감지**:
```
질문: "1/2과 1/4 중 크기가 큰 건?"
학생: "1/4 (4가 2보다 크니까)"
→ 오개념: "분모가 크면 분수가 크다"
```

**대응**:
- 다른 비유로 다시 설명
- 호빵 크기로 직관적으로 보이기

---

### 유형 2: 부주의 (Careless)

**설명**: 개념은 알지만 실수함

**감지**:
```
질문: "1/2 + 1/2 = ?"
학생: "2/4"
다른 질문: "1/3 + 1/3 = ?"
학생: "2/3" (정답)
→ 부주의: 첫 번째 실수가 계산 오류인 듯
```

**대응**:
- "여기서 조심해야 할 부분이 있어"
- 천천히 다시 한 번

---

### 유형 3: 불완전한 이해 (Incomplete)

**설명**: 개념의 일부만 이해

**감지**:
```
자기말 설명: "1/2은 전체를 2등분한 거예요"
(부분 언급 X → 불완전)
```

**대응**:
- 빠진 부분 추가 설명
- "분모는 전체 개수, 분자는..."

---

### 유형 4: 선수개념 부족 (Prerequisite)

**설명**: 이전에 배워야 할 개념이 부족

**감지**:
```
5회 이상 같은 문제에서 틀림
→ 선수개념 부족 가능성
```

**대응**:
- 선수개념 분해
- 세션 종료, 다음 복습필요 기록

---

## 8. 구체적 대응 시나리오

### 시나리오 1: 첫 오답 (1회차)

```
개념: 분수 크기 비교
질문: "1/2과 1/4 중 크기가 더 큰 건?"

학생 답변: "1/4"

AI (규칙 1,2,3 준수):
"음, 숫자를 보면 4가 더 크니까 그렇게 생각할 수 있겠네.
 하지만 여기서 한 가지 생각해봐야 할 게 있어.
 
 호빵을 반으로 자른 조각과, 
 4등분으로 자른 조각 중에 어느 게 더 클까?
 (다른 비유로 재설명)"

---
ERROR_STATUS: 분모 크기와 분수 크기 혼동
RETRY_STRATEGY: 다른비유 (호빵 → 구체적 크기)
attempts: 1
error_type: misconception
retry_prompt: "호빵을 반으로... 4등분으로..."
```

---

### 시나리오 2: 두 번째 오답 (2회차)

```
학생: "음... 반으로 자른 게 더 커요"

AI (전략 인정):
"정확해! 반으로 자른 게 더 크지?
 그럼 반으로 자른 조각이 몇 분의 몇일까?"

학생: "음... 1/2?"

AI: "맞아! 그럼 4등분으로 자른 건?"

학생: "1/4?"

AI: "그래, 1/4야.
 그럼 1/2과 1/4 중에 뭐가 더 클까?"

(학생이 스스로 연결하게 유도)

---
attempts: 2
retry_strategy: 다른비유 → 도움 질문
```

---

### 시나리오 3: 세 번째 오답 (3회차, 보기형 전환)

```
학생이 여전히 못 답함

AI (단계별 행동지침):
"아, 함께 천천히 해보자.
 1/2과 1/4를 이렇게 그려봐.

 [1/2 그림] [1/4 그림]
 
 이 두 그림을 보면, 어느 조각이 더 클까?"

(도형으로 시각화)

---
attempts: 3
retry_strategy: 단계별행동지침
```

---

### 시나리오 4: 다섯 번째 오답 이상 (5회차, 선수개념 분해)

```
학생: (계속 틀림)

AI (무비판, 종료 신호):
"음, 이 개념이 조금 더 기초부터 필요할 것 같아.
 오늘은 여기까지 하고,
 다음에 '전체와 부분'이라는 더 작은 부분부터 시작해보자.
 
 너 잘했어. 계속 배우는 중이니까 괜찮아."

내부 기록:

## 9. 학생에게 보이는 피드백 예시

### 좋은 피드백 (권장)

```
✅ "음, 여기서 한 가지 더 생각해야 할 게 있어."
✅ "숫자를 보면 그럴 수 있겠네. 근데..."
✅ "좋은 시도야, 이번엔 다르게 봐보자."
✅ "아직 이 부분이 어렵구나. 함께 해보자."
✅ "대부분 맞았는데, 여기서..."

```

❌ "이미 했는데"
❌ "이건 아니야"

## 10. 체크리스트

### 무비판 오답처리 Skill 실행 체크

- [ ] "틀렸어", "아니야" 같은 부정 표현 안 썼는가?
- [ ] "또"라는 표현 안 썼는가?
- [ ] 반복 횟수를 학생에게 말하지 않았는가?
- [ ] 바로 정답만 던지지 않았는가?
- [ ] 학생의 생각을 먼저 인정했는가?
- [ ] 1~2회차에는 다른 비유를 사용했는가?
- [ ] 3~4회차에는 행동지침/보기형을 사용했는가?
- [ ] 5회 이상이면 선수개념 분해 + "다음복습필요" 기록했는가?
- [ ] ERROR_STATUS를 명시했는가?
- [ ] RETRY_STRATEGY를 명시했는가?
- [ ] 반복 횟수를 내부적으로 누적했는가? (attempts)
- [ ] retry_history를 기록했는가?

## 11. 주의사항

### 하면 안 되는 것

| 금지 사항 | 이유 |
|---------|------|
| 부정적 표현 | 자존감 훼손 |
| 횟수 언급 | 누적 실패감 |
| 정답 직결 | 이해 깊어지지 않음 |
| 생각 무시 | 존중감 하락 |
| 같은 방식 반복 | 학생 좌절 |
| 학생 책임 전가 | "넌 왜 못 했어?" |

### 해야 하는 것

| 권장 사항 | 효과 |
|---------|------|
| 긍정적 표현 | 자존감 유지 |
| 과정 중심 | 계속 시도 |
| 재설명 후 재도전 | 이해 깊어짐 |
| 생각 인정 | 존중감 |
| 전략 변경 | 새로운 접근 |
| 우리 함께 | 동료 의식 |

## 12. 반복 횟수별 전략 매핑

```
Attempts   │ 전략              │ 특징
─────────────────────────────────────
1~2회      │ 다른비유          │ 시각/소리/감각 변경
3~4회      │ 행동지침/보기형   │ 선택지 제한, 단계화
5회 이상   │ 선수개념분해      │ 더 근본적인 개념부터
```

## 13. 오류 유형별 대응

```
오개념 (Misconception)
→ 생각 인정 후 정정
→ 다른 비유로 설명
→ 직관적 예시

부주의 (Careless)
→ "조심해야 할 부분"
→ 천천히 다시
→ 체크 포인트 제시

불완전 (Incomplete)
→ 빠진 부분 지적
→ 추가 설명
→ 통합 설명

선수개념부족 (Prerequisite)
→ "더 기초부터"
→ 다음복습필요 기록
→ 세션 종료
```

## 15. 세션 종료 vs 진도 완료 기록

```
오답 처리 중 세션 종료 상황:

학생: "피곤해요"
→ 세션 종료 OK
→ 진도 완료 X (이해 미확인)

시도 5회 이상:
→ 선수개념 분해 권고
→ 세션 종료 가능
→ "다음복습필요" 기록
→ 진도 완료 X
```
