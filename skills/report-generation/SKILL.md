# Skill: 과목별/일일 복습 리포트

## 1. 스킬 정의

### 이름
과목별/일일 복습 리포트

### 역할
**세션 완료 후** 복습 결과를 **학생용과 교사/보호자용으로 분화하여 생성**하는 스킬

### 활용 시점
- 과목별 복습 완료 후 (스몰스텝 모두 완료 또는 세션 종료 시)
- 당일 모든 과목 복습 완료 후 (일일 리포트)
- 주간 복습 완료 후 (주간 총괄) - 선택사항

### 입력값
- 완료한 스텝 목록
- 각 스텝별 이해도 기록
- 반복 횟수, 오답 패턴
- 학생의 관심사
- 현재 세션 정보 (학년, 과목, 진도 등)

### 출력값
- **학생용 리포트**: 격려적, 긍정적, 성취감 강조
- **교사/보호자용 리포트**: 객관적, 상세, 지도 포인트 명시

---

## 2. 핵심 원칙

| 원칙 | 설명 | 위반 예시 |
|------|------|---------|
| **완료 먼저** | 성공한 것 강조 | ❌ 부족함부터 시작 |
| **부정 표현 금지** | 실패, 부족, 미달 금지 | ❌ "실패했다", "부족하다" |
| **다음형 표현** | "다음에 이어 할" | ✅ "다음 세션에서..." |
| **점수/등급 금지** | 숫자 평가 금지 | ❌ "80점", "B등급" |
| **분화** | 학생용과 교사용 분리 | ✅ 정보 깊이 다름 |
| **명확한 기록** | 다음 시작 위치 명시 | ✅ "Sub-Step 2부터" |

---

## 3. 절차 (Step-by-Step)

### Step 1: 완료한 스텝을 먼저 보여준다

**목표**: 학생의 성취감 극대화

**순서**:
```
1. 완료한 스텝 (이해완료)
2. 도전한 스텝 (부분이해, 재시도 후 완료)
3. 다음에 할 스텝 (미완료)
```

**예시**:
```
[학생용]
"오늘 분수의 덧셈에서 이만큼 했어.

완료한 것:
✅ Step 1: 분수 개념
✅ Step 2: 분자와 분모
✅ Step 3: 같은 분모 분수

도전한 것:
🔄 Step 4: 분수 덧셈 규칙 (여러 번 시도했지만 다음에 계속)"
```

**심리적 이유**:
```
완료 먼저 → 성취감 ↑ → 다음 복습 동기 ↑
부족함 먼저 → 실패감 ↓ → 회피 동기 ↓
```

---

### Step 2: 실패, 부족, 미달이라는 표현을 쓰지 않는다

**금지 표현**:
```
❌ "실패했다"
❌ "부족하다"
❌ "미달이다"
❌ "틀렸다"
❌ "못했다"
❌ "낙제"
```

**대체 표현**:

| 금지 | 대체 |
|-----|------|
| "실패" | "도전", "여러 번 시도" |
| "부족" | "아직", "다음에 더" |
| "미달" | "진행 중", "계속 배우는 중" |
| "틀렸다" | "다르게 생각해보자" |
| "못했다" | "함께 계속 해보자" |

**예시**:
```
❌ "Step 4에서 실패했어"
✅ "Step 4에서 여러 번 시도했어. 다음 복습에서 계속 해보자"

❌ "분수 덧셈이 부족해"
✅ "분수 덧셈은 다음에 더 깊이 있게 배울 거야"
```

---

### Step 3: 미해결 스텝은 "다음에 이어 할 부분"으로 표현한다

**목표**: 미해결을 진행 중인 학습으로 재해석

**표현 방법**:

| 상황 | 표현 |
|------|------|
| 완료하지 못한 스텝 | "다음 복습에서 이어 할 부분" |
| 선수개념 분해된 경우 | "다음에는 더 기초부터 차근차근" |
| 세션 종료 (피곤) | "오늘은 여기까지, 다음에 계속" |
| 같은 스텝 반복 많음 | "더 깊이 배울 부분" |

**예시**:
```
[학생용]
"다음 복습에서 이어 할 것:
- Step 4: 분수 덧셈 규칙 (더 작은 조각으로)"

[교사용]
"미완료 스텝:
- Step 4 (다음복습필요: 선수개념 분해 권고)"
```

---

### Step 4: 다음 시작 위치를 명확히 기록한다

**목표**: 다음 세션에서 바로 시작할 수 있게 명확히

**기록 형식**:
```json
{
  "next_session_plan": {
    "course": "중1수학",
    "lesson": "분수의 덧셈",
    "resume_from": "Sub-Step 1: 전체와 부분",
    "original_step": "Step 4: 분수 덧셈",
    "reason": "선수개념 분해"
  }
}
```

**학생에게는 자연스럽게**:
```
"다음에 만나면,
'전체와 부분'부터 다시 시작할 거야.
그럼 분수가 더 쉬워질 거야!"
```

---

### Step 5: 점수나 등급을 표시하지 않는다

**금지**:
```
❌ "80점"
❌ "B등급"
❌ "정답률 60%"
❌ "5/10"
❌ "합격/불합격"
```

**대신 사용**:
```
✅ "이해완료", "부분이해", "도전 중"
✅ "잘한 점: 분수 개념을 명확히 이해했어"
✅ "다음 포인트: 분자/분모의 역할 구분"
✅ "반복된 부분: 분수 크기 비교"
```

## 4. 학생용 리포트 구조

### 형식

```
[제목]
오늘 (과목) (진도)에서 이만큼 했어!

[완료한 것 - 성취감 강조]
✅ Step 1: (개념명)
✅ Step 2: (개념명)
...

[도전한 것 - 노력 인정]
🔄 Step X: (개념명) 
   (여러 번 시도했지만 다음에 계속)

[잘한 점 - 구체적 칭찬]
- (구체적 행동/태도)
- (이해의 깊이)
- (노력의 흔적)

[다음에 이어 할 것 - 기대감]
- (다음 개념)
  → (그러면 더 쉬워질 거야)

[격려 메시지]
너 정말 잘했어. 계속하면 더 좋아질 거야!
```

---

### 예시 1: 완전 완료

```
오늘 중1 수학 '분수의 덧셈'에서 이만큼 했어!

✅ 완료한 것:
- Step 1: 분수 개념 (전체를 같은 크기로 나눈 것)
- Step 2: 분자와 분모 (위는 취한 부분, 아래는 전체)
- Step 3: 같은 분모 분수 (분모가 같을 때 비교)
- Step 4: 분수 덧셈 규칙 (분자끼리 더하기)

🌟 잘한 점:
- 분수 개념을 호빵으로 정확히 이해했어
- 실수해도 다시 도전하는 마음이 멋있었어
- 자기 말로 설명할 때 명확했어

다음 복습 때:
- Step 5: 분수 뺄셈 (비슷한 방식이니까 쉬워질 거야!)

정말 잘했어! 계속 이렇게 하면 분수 정말 쉬워질 거야! 🎉
```

---

### 예시 2: 부분 완료 (선수개념 분해)

```
오늘 중1 수학 '분수의 덧셈'에서 이만큼 했어!

✅ 완료한 것:
- Step 1: 분수 개념
- Step 2: 분자와 분모

🔄 도전한 것:
- Step 3: 같은 분모 분수
  여러 번 시도했지만 다음 복습에서 다시 해보자

🌟 잘한 점:
- 어려워도 포기하지 않고 계속 시도했어
- 분자/분모는 정확히 이해했어
- "더 작은 조각으로" 배우는 걸 잘 받아들였어

다음 복습 때:
- 먼저 '나누기'와 '전체와 부분'부터 다시 배워보자
- 그럼 분모가 뭔지 더 명확해질 거야

너는 정말 잘하고 있어! 지금까지 한 노력이 다 도움이 될 거야 💪
```

## 5. 교사/보호자용 리포트 구조

### 형식

```
[기본 정보]
학교급: 초등 / 중등
학년: (학년)
과목: (과목)
진도: (단원명 또는 페이지)
세션 날짜: (날짜)
세션 시간: (소요 시간)

[학습 진행]
완료 스텝: 
- Step 1, 2, 3... (스텝명)

부분 통과 스텝:
- Step X (오답 유형, 반복 횟수)

다음복습필요 스텝:
- Step Y (이유)

[학습 패턴 분석]
- 강점 개념: (명확히 이해한 개념)
- 약점 개념: (반복된 개념)
- 반복이 많았던 부분: (개념명) - (반복 횟수)회
- 오개념 감지: (있으면 명시)
- 반응 패턴: (학생의 학습 특성)

[다음 복습 계획]
다음 시작 위치: (구체적 위치)
- (Sub-Step 또는 Step 명시)
- (이유)

추천 지도 포인트:
- (학부모/교사가 주목할 지점)
- (가정에서의 지원 방법)
- (다음 복습 시 체크할 사항)

[참고]
- 학생 관심사: (활용된 관심사)
- 세션 종료 이유: (정상 종료 / 피곤 / 선수개념분해 등)
```

---

### 예시 1: 완전 완료

```
[기본 정보]
학교급: 중등
학년: 1학년
과목: 수학
진도: 분수의 덧셈
세션 날짜: 2026-07-02
세션 시간: 약 25분

[학습 진행]
✅ 완료 스텝: 4/4
- Step 1: 분수 개념 (1회 만에 이해)
- Step 2: 분자와 분모 (2회 반복 후 이해)
- Step 3: 같은 분모 분수 (1회 만에 이해)
- Step 4: 분수 덧셈 규칙 (1회 만에 이해)

[학습 패턴 분석]
강점 개념: 
- 분수 개념 (구체적 예시로 빠르게 이해)
- 비교/판단 능력 (호빵 예시로 직관적 판단)

약점 개념: 
- 용어 정의 (분자/분모 2회 반복)
- 기호와 의미의 연결 (초기에 어려움)

반응 패턴:
- 구체적 예시(호빵, 초콜릿)에 반응 잘함
- 자기말 설명으로 이해도 검증 효과적
- 긍정적 피드백에 동기 증가

[다음 복습 계획]
다음 시작 위치: 분수의 뺄셈 (Step 1부터)
- 덧셈과 유사한 구조이므로 자연스러운 진행
- 같은 분모 뺄셈부터 시작 권고

추천 지도 포인트:
- 가정에서: 호빵/초콜릿 등으로 나누기 활동 권고
- 다음 복습: "오늘은 곱셈을 배웠으니까, 역으로 나누기"라는 연결 강조
- 체크: 분자/분모의 위치 반복 확인

[참고]
- 학생 관심사: 축구 (축구 경기 시간으로 분수 설명 활용)
- 세션 종료: 정상 종료 (모든 스텝 완료, 학생 에너지 유지)
```

---

### 예시 2: 부분 완료 (선수개념 분해)

```
[기본 정보]
학교급: 중등
학년: 1학년
과목: 수학
진도: 분수의 덧셈
세션 날짜: 2026-07-02
세션 시간: 약 30분

[학습 진행]
✅ 완료 스텝: 2/4
- Step 1: 분수 개념 (1회)
- Step 2: 분자와 분모 (재설명 후 이해)

⚠️ 부분 통과 스텝: 1/4
- Step 3: 같은 분모 분수 (3회 반복 후 부분이해)

🔄 다음복습필요 스텝: 1/4
- Step 4: 분수 덧셈 규칙 (선수개념 분해 실행)

[학습 패턴 분석]
강점 개념:
- 분수의 기본 개념 (이해 빠름)
- 구체적 사물로의 연결 가능

약점 개념:
- 분모의 의미 파악 (같은 분모 비교에서 혼동)
- 추상적 개념화 (기호 → 의미 연결)

반복 분석:
- Step 3: 3회 반복
  * 1회: "1/2이 1/4보다 크다" (오개념)
  * 2회: 비유로 재설명
  * 3회: 보기형으로 부분 이해

오개념 감지:
- "분모가 크면 분수도 크다" (감지 후 정정)

반응 패턴:
- 시각적 자료(그림/도형)에 강함
- 선택지 형식에서 더 잘 응답
- 반복되면 혼동 증가 → 전략 변경 필요

[다음 복습 계획]
다음 시작 위치: Sub-Step 1 "전체와 부분 명확히 하기"
- 이유: Step 3과 4의 선수개념 부족 감지
- 더 작은 개념(나누기, 전체와 부분)부터 강화
- 예상 스텝: 2~3회 소요

추천 지도 포인트:
- 가정에서: 초콜릿/피자를 직접 나누는 활동 강력 권고
- 시각화: 그림/도형으로 표현하는 습관 형성
- 체크: 분모의 의미("전체를 나눈 개수") 반복 확인
- 언어: "1/4는 4개 중 1개"라는 명확한 표현 강조

[참고]
- 학생 관심사: 게임 (게임 아이템 분배로 설명 시도하였으나 비효과적)
- 효과적 학습법: 호빵/초콜릿 같은 실물 중심
- 세션 종료 이유: 선수개념 분해 실행 (학생 상태는 좋음)
- 추가 노트: 과제분석 재설계 권고 (현재 Level 2 스텝이 Level 1에 맞음)
```

## 6. 학생용 vs 교사용 정보 차이

| 항목 | 학생용 | 교사용 |
|------|--------|--------|
| 완료 | "이만큼 했어!" | "4/4 완료" |
| 반복 | "여러 번 시도" | "Step 3: 3회 반복" |
| 오개념 | "다르게 생각해보자" | "분모 크기 혼동 감지" |
| 다음 | "다음에 계속" | "Sub-Step 1부터 재시작" |
| 이유 | (노출 X) | "선수개념 부족" |

## 9. 체크리스트

### 과목별/일일 복습 리포트 생성 체크

**학생용 리포트**:
- [ ] 완료한 스텝을 먼저 보여주었는가?
- [ ] 격려적이고 긍정적인 톤인가?
- [ ] 점수/등급/숫자 평가 없는가?
- [ ] "실패", "부족", "미달" 표현 없는가?
- [ ] 미해결을 "다음에 이어 할"로 표현했는가?
- [ ] 다음 시작 위치를 명확히 했는가?
- [ ] 구체적인 칭찬이 있는가?

**교사/보호자용 리포트**:
- [ ] 기본 정보(학년, 과목, 진도)를 명시했는가?
- [ ] 완료/부분/미완료 스텝을 구분했는가?
- [ ] 반복 횟수를 정확히 기록했는가?
- [ ] 오개념을 감지했으면 명시했는가?
- [ ] 강점과 약점을 명확히 했는가?
- [ ] 다음 시작 위치와 이유를 명확히 했는가?
- [ ] 지도 포인트를 구체적으로 제시했는가?
- [ ] 세션 종료 이유(정상/피곤/분해)를 기록했는가?

## 10. 주의사항

### 하면 안 되는 것

| 금지 사항 | 이유 |
|---------|------|
| 부정 표현 | 학생 자존감 훼손 |
| 점수/등급 | 숫자 중심 평가 |
| 부족함 먼저 | 성취감 저하 |
| 비교 | 상대 평가 (피해) |
| 이유 설명 X | 학부모 혼동 |
| 다음 위치 모호 | 진도 파악 실패 |

### 해야 하는 것

| 권장 사항 | 효과 |
|---------|------|
| 완료 먼저 | 성취감 ↑ |
| 격려 메시지 | 동기 ↑ |
| 구체적 칭찬 | 신뢰성 ↑ |
| 명확한 다음 | 계획성 ↑ |
| 정보 분화 | 활용성 ↑ |
