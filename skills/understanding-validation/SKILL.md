# Skill: 자기말 설명 기반 이해도검증

## 1. 스킬 정의

### 이름
자기말 설명 기반 이해도검증

### 역할
개념설명 후 학생의 **자기말 설명을 분석**하여 **진짜 이해했는지(표면적 이해 아님) 파인만식으로 검증**하는 스킬

### 활용 시점
- 개념설명 완료 후, 학생이 자기말로 설명한 직후
- "방금 배운 걸 네 말로 한 문장만 말해볼래?"에 대한 답변 분석

### 입력값
- 현재 개념명 (concept_name)
- 설명해야 할 핵심 키워드 (학습목표에서 추출)
- 학생의 자기말 설명 (자유 텍스트)

### 출력값
- UNDERSTANDING_STATUS (이해완료 / 부분이해 / 오개념 / 응답부족)
- 상세 분석 결과
- 다음 액션 (미니퀴즈 / 재설명 / 보기형 제시)

---

## 2. 핵심 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **파인만식 검증** | "이해했어" 말로 넘어가지 않기 | 반드시 자기말 설명 분석 |
| **핵심 키워드** | 핵심을 5개 이상 포함해야 이해 | "분수"만 말하면 안 됨 |
| **자기 말인가** | 암기가 아닌 실제 이해 구분 | "호빵을 반으로 나눈 것" vs "전체를 이등분" |
| **오개념 감지** | 틀린 이해는 이해가 아님 | "분자가 클수록 분수가 작다" 감지 |
| **응답 부족 허용** | 너무 짧으면 다시 물어보기 | "네" "몰라" 같은 답변은 재질문 |
| **부정 표현 금지** | 틀린 답변도 존중하는 톤 | ❌ "틀렸어", ✅ "여기서 한 가지 더..." |

---

## 3. 판단 기준 5가지

### 기준 1: 핵심 키워드를 포함했는가?

**목표**: 개념의 핵심 요소를 학생이 언급했는지 확인

**예시 1 - 분수의 개념**:
```
핵심 키워드: "전체", "나누기", "부분", "같은 크기"

학생 답변 1:
"전체를 같은 크기로 나누고, 그 중 하나를 1/2라고 해요"
→ 핵심 4개 모두 포함 ✅ (전체, 나누기, 같은 크기, 부분)

학생 답변 2:
"호빵을 반으로 나눈 거예요"
→ 핵심 3개 포함 ✅ (나누기, 같은 크기, 부분)
→ "전체"는 암시적으로 포함

학생 답변 3:
"음... 그냥 분수예요"
→ 핵심 0개 ❌
```

**예시 2 - 분자와 분모**:
```
핵심 키워드: "위(분자)", "아래(분모)", "개수", "전체"

학생 답변 1:
"위의 1은 내가 먹는 개수, 아래 4는 전체를 4등분한 개수예요"
→ 핵심 4개 모두 ✅

학생 답변 2:
"분자는 위, 분모는 아래"
→ 핵심 2개 (위, 아래) ⚠️ (개념의 의미 부족)

학생 답변 3:
"분자는 1, 분모는 4"
→ 구체적 숫자만 ❌ (개념 미이해)
```

**판정 방법**:
- 핵심 키워드 3개 이상 포함: ✅
- 핵심 키워드 1~2개만: ⚠️ (추가 확인 필요)
- 핵심 키워드 0개: ❌

---

### 기준 2: 개념의 뜻을 자기 말로 표현했는가?

**목표**: 단순 암기가 아닌 자신의 언어로 설명했는지 확인

**암기 vs 실제 이해**:

| 암기 (위험) | 실제 이해 (좋음) |
|----------|-------------|
| "분수는 전체를 같은 크기로 나눈 것이다" (그대로) | "호빵을 4조각으로 깨뜨렸을 때, 그 중 1조각" |
| "분자는 위, 분모는 아래" (정의 암기) | "위는 내가 먹은 조각, 아래는 전체 조각 수" |
| "1/2은 0.5" (공식 암기) | "전체를 2등분했을 때 반개" |

**판정 방법**:
```
학생 표현이...
- "호빵", "초콜릿" 같은 구체적 사례 포함?
  → 실제 이해 가능성 높음 ✅
  
- 교과서 문장을 그대로 반복?
  → 암기 가능성 높음 ❌
  
- 본인의 일상으로 연결?
  → 실제 이해 확실 ✅✅
```

**예시**:
```
개념: 분자와 분모

학생 답변 1: "위를 분자, 아래를 분모라고 해요"
→ 암기 수준 ❌

학생 답변 2: "위는 내가 먹은 조각 수, 아래는 전체 조각 수예요"
→ 개념 이해 ✅

학생 답변 3: "피자를 8조각으로 나누었는데, 내가 2조각을 먹으면 
            그게 2/8이고, 여기서 2가 분자, 8이 분모예요"
→ 실제 적용 이해 ✅✅
```

---

### 기준 3: 단순 암기인지 실제 이해인지 구분한다

**목표**: 표면적 암기와 깊은 이해 구분

**암기 신호**:
- 정확한 문장인데, 설명을 못함
- "그냥 그래요"
- 응용 질문에 답 못함

**이해 신호**:
- 표현은 부정확할 수 있지만, 개념의 핵심을 말함
- "왜 그럴까?" 질문에 설명 가능
- 다른 예시에도 적용 가능

**판정 테스트**:
```
학생이 "1/2는 전체를 반으로 나눈 것"이라고 했다

추가 질문: "그럼 1/3은?"
→ "전체를 3등분하는 거" 답함 = 이해 ✅
→ "모르겠어요" 답함 = 암기 ❌
```

---

### 기준 4: 오개념이 섞였는가?

**목표**: 잘못된 개념을 학생이 갖고 있는지 감지

**오개념 예시**:

| 개념 | 올바른 이해 | 오개념 |
|------|----------|------|
| 분수 크기 | 1/2 > 1/4 | 1/4 > 1/2 ("4가 크니까 1/4가 더 크다") |
| 분자/분모 | 분자는 취한 부분, 분모는 전체 | 분자/분모가 뭔지 뒤바뀜 |
| 분수 덧셈 | 1/2 + 1/2 = 1 | 1/2 + 1/2 = 2/4 (분자끼리, 분모끼리만) |
| 접속사 | "~서"는 이유 | "~서"는 대조 |
| 과거형 | walked는 walk의 과거형 | walked는 새로운 단어 |

**판정 방법**:
```
학생 설명에 오개념이 섞여있으면?
→ UNDERSTANDING_STATUS = "오개념" (부분이해 아님)
→ 정정 필요, 재설명 필수
```

**예시**:
```
개념: 분수의 크기 비교

학생: "1/2는 위가 1이고 아래가 2니까, 1/3보다 작아요"
→ 오개념: 분모가 크면 분수가 작다는 역함수 개념 미포함
→ STATUS = "오개념"
```

---

### 기준 5: 답변이 너무 짧아 판단이 어려운가?

**목표**: 충분한 정보 없이 이해도 판단 못하는 경우 감지

**응답 부족 신호**:

| 응답 | 판정 |
|------|------|
| "네" | 부족 ❌ |
| "알겠어요" | 부족 ❌ |
| "음... 모르겠어요" | 부족 ❌ |
| "뭔지는 알 것 같은데..." | 부족 ❌ |
| "분수는 분수예요" | 부족 ❌ |
| "호빵을 반으로 나누는 거" | 충분함 ✅ |

**대응 방법**:
```
답변이 너무 짧으면?
→ UNDERSTANDING_STATUS = "응답부족"
→ 보기형이나 빈칸형으로 다시 물어보기
```

**예시**:
```
AI: "방금 배운 걸 네 말로 한 문장만 말해볼래?"

학생: "네, 알겠어요"
→ 응답부족
→ 재질문: "그럼 1/2가 뭐라고 설명할 수 있어?"

학생: "호빵 반개?"
→ 여전히 부족
→ 보기형: "1/2는 전체를 2등분한 것 중 (  )개지?"
          ① 1개    ② 2개
```

## 4. 결과 분류 4가지

### 결과 1: 이해완료 ✅

**조건** (모두 만족):
- 핵심 키워드 3개 이상 포함
- 자기 말로 설명 (암기 아님)
- 오개념 없음
- 응답 충분함

**학생 메시지**:
```
"정확하네! 분수가 뭔지 정확히 이해했어."
"맞아, 그렇게 생각하면 돼."
```

**다음 액션**: 미니퀴즈로 진행

**예시**:
```
개념: 분수 개념

학생: "호빵을 4개로 깨뜨렸을 때, 그 중 하나가 1/4라는 뜻이에요"

분석:
- 핵심 키워드: "전체"(호빵), "나누기"(깨뜨림), "부분"(하나), "같은 크기"(암시적) ✅
- 자기 말: "호빵 깨뜨리기" 구체적 ✅
- 오개념: 없음 ✅
- 응답: 충분 ✅

→ UNDERSTANDING_STATUS = "이해완료"
```

---

### 결과 2: 부분이해 ⚠️

**조건** (다음 중 해당):
- 핵심 키워드 1~2개만 포함
- 자기 말이지만, 일부만 설명
- 오개념은 없음
- 응답은 충분

**학생 메시지**:
```
"좋아, 분자/분모 부분은 맞는데, 
 분수가 뭐라고 생각하는지 다시 한 번 말해볼래?"
"방금 말한 거 좋아, 근데 좀 더..."
```

**다음 액션**: 비슷한 개념 또는 다른 비유로 재설명

**예시**:
```
개념: 분자와 분모

학생: "분자는 위, 분모는 아래예요"

분석:
- 핵심 키워드: "위", "아래" (2개만) ⚠️
- 자기 말: 맞지만 의미 부족
- 오개념: 없음 ✅
- 응답: 충분 ✅

→ UNDERSTANDING_STATUS = "부분이해"
→ 재질문: "분자는 위니까... 뭘 나타내는 거야?"
```

---

### 결과 3: 오개념 ❌

**조건**:
- 오개념이 섞여있음 (핵심 키워드 포함 여부와 무관)

**학생 메시지**:
```
"그 부분이 조금 다를 수 있어. 함께 다시 봐보자."
"좋은 생각인데, 여기서 조금 다르게 생각해야 돼."
```

**다음 액션**: 무비판 재설명 (오개념 명확히 정정 필요)

**예시 1**:
```
개념: 분수 크기 비교

학생: "1/4가 1/2보다 커요. 왜냐하면 4가 2보다 크니까."

분석:
- 핵심 키워드: 있지만... 
- 오개념: 분모 크기와 분수 크기를 혼동 ❌

→ UNDERSTANDING_STATUS = "오개념"
→ 재설명: "아, 분모가 크다고 분수가 크게 되는 게 아니야.
          오히려 반대야. 호빵을 4등분하는 게 2등분하는 것보다 작은 조각이 되지."
```

**예시 2**:
```
개념: 분수 덧셈

학생: "1/2 + 1/3을 더할 때, 분자끼리 더하고 분모끼리 더해요.
      그럼 2/5가 돼요"

분석:
- 핵심 키워드: 있음
- 오개념: 통분 개념 미포함, 잘못된 계산 방법 ❌

→ UNDERSTANDING_STATUS = "오개념"
→ 재설명: "음, 분자끼리 분모끼리만 더하면 안 돼.
          먼저 분모를 같게 만들어야 해. 이걸 통분이라고 해."
```

---

### 결과 4: 응답부족 ⏸️

**조건**:
- 응답이 너무 짧거나 모호함
- 이해도 판단 불가능

**학생 메시지**:
```
"음, 조금 더 설명해볼래?"
"뭐라고 설명하면 쉬울까?"
"예를 들어 말해볼래?"
```

**다음 액션**: 보기형 또는 빈칸형으로 재질문

**예시 1**:
```
개념: 분수 개념

학생: "분수는... 음... 뭐예요"

분석:
- 응답 부족 ⏸️

→ UNDERSTANDING_STATUS = "응답부족"
→ 보기형 제시: "분수는 전체를 (  )로 나눈 것 중 (  )개를 말해.
                ① 크기, 부분
                ② 갯수, 모양
                ③ 같은 크기, 부분"
```

**예시 2**:
```
개념: 부사절 접속사 "~서"

학생: "음... 접속사는 연결하는 거? 맞나?"

분석:
- 응답 부족 (확신이 없는 듯) ⏸️

→ UNDERSTANDING_STATUS = "응답부족"
→ 빈칸형: "'비가 와서 우산을 쓴다'에서 
          '와서'의 뜻은 뭐야?
          ① 이유  ② 대조  ③ 시간"
```

## 5. 판단 기준 매트릭스

| 핵심KW | 자기말 | 오개념 | 응답 | 결과 |
|--------|--------|--------|------|------|
| 3+ | ✅ | ❌ | ✅ | **이해완료** |
| 1~2 | ✅ | ❌ | ✅ | **부분이해** |
| any | any | ✅ | ✅ | **오개념** |
| any | any | ❌ | ⏸️ | **응답부족** |
| 0 | ❌ | ❌ | ✅ | **부분이해** or **응답부족** |

## 7. 필드 상세 설명

| 필드 | 설명 | 예시 |
|------|------|------|
| **UNDERSTANDING_STATUS** | 4가지 결과 중 하나 | "이해완료" |
| **STATUS** | 현재 상태 | "이해도검증 완료" |
| **NEXT** | 다음 액션 설명 | "미니퀴즈로 진행" |
| **student_explanation** | 학생의 자기말 설명 (그대로) | "호빵을 반으로 나눈 거" |
| **keywords_found** | 찾은 핵심 키워드 | ["전체", "나누기", "부분"] |
| **keywords_count** | 찾은 키워드 개수 | 3 |
| **required_keywords** | 필요한 핵심 키워드 목록 | ["전체", "나누기", "같은크기", "부분"] |
| **is_own_language** | 자기 말인가 | true |
| **has_misconception** | 오개념 포함 여부 | false |
| **misconception_detail** | 오개념 설명 (있으면) | "분모 크기와 분수 크기 혼동" |
| **response_sufficiency** | 응답 충분성 | "sufficient" |
| **confidence_score** | 이해도 신뢰도 (0~1) | 0.85 |
| **feedback_type** | 피드백 유형 | "positive" (이해완료), "redirect" (부분/오개념), "clarify" (응답부족) |
| **next_action** | 다음 구체적 액션 | "mini_quiz", "rephrase", "ask_again", "provide_multiple_choice" |

## 8. 진도별 판단 예시

### 예시 1: 분수 개념 (START_LEVEL = 2)

**학습 목표**: "전체를 같은 크기로 나눈 것 중 하나를 분수라고 한다"

**필수 키워드**: ["전체", "나누기", "같은크기", "부분"]

**학생 설명 (Turn 1)**:
```
"호빵을 반으로 나눈 거"

분석:
- 키워드: "나누기"(반으로), "부분"(나눈 거) → 2개 ⚠️
- 자기 말: "호빵", "반으로" → 구체적 ✅
- 오개념: 없음 ✅
- 응답: 짧지만 충분 ✅

→ UNDERSTANDING_STATUS = "부분이해"
→ NEXT = "분자/분모 설명하기"
```

**학생 설명 (Turn 2 - 동일 개념 재설명 후)**:
```
"전체 호빵을 2등분했을 때 그 중 1개가 1/2예요"

분석:
- 키워드: "전체"(호빵), "나누기"(2등분), "같은크기"(암시), "부분"(1개) → 4개 ✅
- 자기 말: 구체적 예시로 설명 ✅
- 오개념: 없음 ✅
- 응답: 충분 ✅

→ UNDERSTANDING_STATUS = "이해완료"
→ NEXT = "미니퀴즈로 이동"
```

---

### 예시 2: 분자와 분모 (START_LEVEL = 1)

**학습 목표**: "분자(위)는 취한 부분의 개수, 분모(아래)는 전체를 나눈 개수"

**필수 키워드**: ["위(분자)", "아래(분모)", "취한부분개수", "전체개수"]

**학생 설명**:
```
"1/4에서 1이 분자고 4가 분모예요"

분석:
- 키워드: "분자", "분모" → 용어만, 의미 없음 ❌
- 자기 말: 암기 가능성 높음 ⚠️
- 오개념: 없음 (잘못된 건 아님) ✅
- 응답: 충분하지만 얕음 ⚠️

→ UNDERSTANDING_STATUS = "응답부족" (의미를 못 설명)
→ NEXT = "보기형 재질문"
→ 보기형: "1/4에서 위의 1은 뭐를 나타내는 거야?"
          ① 내가 먹은 조각 수
          ② 전체 조각 수
          ③ 호빵의 크기
```

---

### 예시 3: 분수 크기 비교 (START_LEVEL = 2)

**학습 목표**: "분모가 같으면 분자가 클수록 분수가 크다"

**필수 키워드**: ["분자", "분모", "크기", "비교"]

**학생 설명**:
```
"1/2가 1/4보다 커요. 
 왜냐하면 호빵을 2등분하는 게 4등분하는 것보다 큰 조각이 되니까."

분석:
- 키워드: "분자"(암시), "분모"(2, 4), "크기"(커요), "비교"(~보다) → 4개 ✅
- 자기 말: 구체적 호빵 예시 ✅
- 오개념: 없음 ✅ (분모로 올바르게 비교)
- 응답: 충분하고 상세 ✅

→ UNDERSTANDING_STATUS = "이해완료"
→ NEXT = "미니퀴즈"
```

---

### 예시 4: 부사절 접속사 (START_LEVEL = 3)

**학습 목표**: "'~서'는 앞뒤의 이유를 연결하는 접속사"

**필수 키워드**: ["이유", "연결", "앞뒤", "접속사"]

**학생 설명 1 (오개념)**:
```
"'비가 와서 우산을 쓴다'에서 
 앞뒤가 대조 관계라고 생각해요"

분석:
- 키워드: "앞뒤"(있음), "접속사"(암시) → 적음
- 오개념: 이유가 아니라 대조로 생각 ❌

→ UNDERSTANDING_STATUS = "오개념"
→ FEEDBACK = "음, 이건 대조가 아니라 이유 관계야.
             비가 오는 게 우산을 쓰는 이유잖아."
```

**학생 설명 2 (이해완료)**:
```
"'~서'는 앞의 일이 뒤의 일의 이유가 돼.
 비가 와서 우산을 쓴다는 건 
 비 때문에 우산을 쓴다는 뜻이에요"

분석:
- 키워드: "이유", "연결", "앞뒤" → 3개 ✅
- 자기 말: 원인-결과 관계 명확 ✅
- 오개념: 없음 ✅
- 응답: 충분하고 정확 ✅

→ UNDERSTANDING_STATUS = "이해완료"
```

## 12. 신뢰도 점수 계산 (confidence_score)

```
confidence_score = (키워드점수 + 표현점수 + 오개념점수 + 응답점수) / 4

각 점수:
- 키워드점수: 3+개면 1.0, 1~2개면 0.5, 0개면 0.0
- 표현점수: 자기말이면 1.0, 암기면 0.0
- 오개념점수: 없으면 1.0, 있으면 0.0
- 응답점수: 충분하면 1.0, 부족하면 0.5

예시:
이해완료의 경우: (1.0 + 1.0 + 1.0 + 1.0) / 4 = 1.0
부분이해의 경우: (0.5 + 1.0 + 1.0 + 1.0) / 4 = 0.875
오개념의 경우: (1.0 + 1.0 + 0.0 + 1.0) / 4 = 0.75
응답부족의 경우: (0.0 + 0.0 + 1.0 + 0.5) / 4 = 0.375
```
