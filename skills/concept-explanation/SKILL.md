# Skill: 3줄 이하 개념설명

## 1. 스킬 정의

### 이름
3줄 이하 개념설명

### 역할
현재 스몰스텝의 **핵심 개념을 3줄 이하로 간결하고 쉽게 설명**하는 스킬

### 활용 시점
- 과제분석(스몰스텝 생성) 완료 후
- 각 스텝마다 반복 (스텝 1 → 스텝 2 → 스텝 3 ...)
- 학생이 이해하지 못해 재설명이 필요할 때

### 입력값
- 현재 스텝 번호
- 설명할 개념명
- 학생의 관심사 (INTERESTS)
- 이전에 사용한 비유 목록 (이미 사용한 비유는 다시 안 쓰기 위해)

### 출력값
- 3줄 이하 설명
- 사용한 비유/예시
- 학생의 자기말 설명 대기

---

## 2. 핵심 원칙

| 원칙 | 설명 | 위반 예시 |
|------|------|---------|
| **3줄 제한** | 절대 4줄 이상 금지 | ❌ "분수는 전체를 나눈 것이고... (5줄 이상)" |
| **1개 개념** | 여러 개념 섞지 않기 | ❌ "분자, 분모, 덧셈 규칙 모두 설명" |
| **쉬운 말** | 어려운 용어는 쉬운 말로 | ✅ "분자"보다 "위 숫자" |
| **관심사 우선** | 학생 관심사로 비유 | ✅ "축구 선수 3명 중 2명" (축구 관심사) |
| **어색하면 일반 소재** | 억지로 연결 금지 | ❌ "음악을 좋아하니까 분수를..." (관계 없음) |
| **새로운 비유** | 이미 사용한 비유는 다시 안 씀 | ❌ "호빵" 2번 사용 |
| **설명 후 문제 금지** | 바로 퀴즈/문제 내지 않기 | ❌ "설명 완료. 이제 문제 풀어봐" |
| **자기말 설명 필수** | "이해했어?"가 아니라 "네 말로 말해봐" | ✅ "방금 배운 걸 네 말로..." |

---

## 3. 절차 (Step-by-Step)

### Step 1: 현재 스텝과 개념 확인

**목표**: 무엇을 설명할지 명확히 함

**필드 확인**:
- `current_step`: 예) 1, 2, 3
- `current_concept`: 예) "분수의 크기 비교"
- `learning_path`: 전체 스몰스텝 목록

**예시**:
```
learning_path: ["Step 1: 분수 개념", "Step 2: 분자/분모", "Step 3: 분수 크기 비교"]

현재: Step 2 (분자/분모만 설명)
→ Step 3 (분수 크기 비교)는 아직 말하지 않음
```

---

### Step 2: 개념을 3줄 이하로 준비

**목표**: 설명을 미리 작성하여 3줄 이하임을 확인

**방법**:
1. 핵심 아이디어 1개 정하기
2. 3줄 이하로 표현하기
3. 어려운 용어 제거하기

**예시 - 좋은 경우**:
```
[Step 1: 분수 개념]

설명 1줄: "분수는 전체를 같은 크기로 나눈 것이야."
설명 2줄: "호빵을 4등분 했을 때 그 중 1개를 분수로 1/4라고 써."
합계: 2줄 ✅

[Step 2: 분자/분모]

설명 1줄: "1/4에서 위의 '1'을 분자, 아래의 '4'를 분모라고 해."
설명 2줄: "분자는 '내가 먹는 개수', 분모는 '전체 나눈 개수'라고 생각해도 돼."
합계: 2줄 ✅
```

**예시 - 나쁜 경우**:
```
❌ "분수란 전체를 같은 크기의 부분으로 나눈 것을 나타내는 수학적 표현이며, 
   분자와 분모로 이루어져 있고, 분자는 취한 부분의 개수이고, 
   분모는 전체를 나눈 개수이며, 따라서 1/4는..."
   (7줄 이상)
```

---

### Step 3: 관심사 활용 (가능하면)

**목표**: 학생의 관심사로 예시 들어서 흥미 유지

**조건**:
- 학생의 관심사가 있으면 우선 사용
- 자연스럽고 억지가 아니어야 함
- 개념과 실제로 연결되어야 함

**예시 1 - 축구 관심사**:
```
INTERESTS: ["축구"]

설명:
"1/2는 전체를 2등분 한 것 중 1개야. 
 축구 선수 11명을 2팀으로 나누면 각 팀이 11/2... 
 아니다, 이건 복잡해. 다시."

→ 이건 억지 같음. 일반 소재로 변경

개선:
"1/2는 전체를 2등분한 것 중 1개야.
 축구 경기가 45분씩 2개 반으로 나뉘잖아. 
 그럼 전반 45분은 전체 경기의 1/2이야."

→ 자연스럽고 축구와 연결됨 ✅
```

**예시 2 - 게임 관심사**:
```
INTERESTS: ["게임", "배틀그라운드"]

설명:
"분자/분모를 이해하려면... 
 배틀그라운드에서 100명이 내려왔는데 20명이 살아남았어. 
 그럼 생존율은 20/100 = 1/5이야."

→ 게임과 자연스럽게 연결됨 ✅
```

**어색한 연결 판단**:
```
❌ "음악을 좋아하니까 분수를..."
   (개념과 관계 없음)

❌ "축구를 좋아하니까 분수는 
   교향곡처럼 다양한 음정의..."
   (억지스러움)

✅ "축구를 좋아하니까 
   경기 시간 1/2, 팀의 일부 선수 수..." 
   (자연스러운 연결)
```

---

### Step 4: 어려운 용어는 쉬운 말로 바꾸기

**목표**: 초중학생이 이해할 수 있게 단순화

**용어 전환**:

| 어려운 용어 | 쉬운 말 |
|-----------|-------|
| 분자 | 위 숫자, 위의 수 |
| 분모 | 아래 숫자, 아래의 수 |
| 덧셈 | 더하기 |
| 뺄셈 | 빼기 |
| 동치분수 | 크기가 같은 분수 |
| 통분 | 같은 크기로 나누기 |
| 약분 | 간단하게 만들기 |
| 접속사 | 문장을 연결하는 말 |
| 주절 | 혼자서도 문장이 되는 부분 |
| 종속절 | 혼자서는 안 되고 다른 말이 필요한 부분 |
| 과거형 | 지난 일을 나타내는 형태 |
| 규칙동사 | 규칙을 따르는 동사 |

**적용 예시**:
```
❌ "분자와 분모의 최대공약수로 약분하면..."

✅ "위 숫자와 아래 숫자를 같은 수로 나누면 
   더 간단하게 만들 수 있어."
```

---

### Step 5: 이미 사용한 비유는 다시 안 쓰기

**목표**: 같은 비유로 이해 못했으면 다른 방식으로 설명

**기록**: `used_analogies` (이전에 사용한 비유 목록)

**예시**:
```
[Step 1 - 첫 번째 설명]
USED_ANALOGY: "호빵 나누기"

학생: "음... 아직 모르겠어요"

[Step 2 - 재설명]
❌ "호빵 1/2은..."
   (같은 비유, 다시 사용)

✅ "초콜릿 한 판을 4조각으로 깨뜨렸을 때, 
   그 중 1조각이 1/4야."
   (다른 비유 사용) ✅
```

**비유 저장소**:
- 식재료: 호빵, 초콜릿, 피자, 케이크
- 스포츠: 축구, 야구, 농구, 게임
- 일상: 돈, 시간, 길이, 친구

---

### Step 6: 설명 후 바로 문제를 내지 않기

**목표**: 개념 설명과 문제 푸는 것을 분리

**금지**:
```
❌ "자, 설명했으니까 이제 1/2 + 1/3을 계산해봐."
   (바로 문제)

❌ "이해했지? 좋아, 그럼 문제 풀어."
   (확인 없이 문제)
```

**올바른 방법**:
```
✅ "방금 배운 걸 네 말로 한 문장만 말해볼래?"
   (설명 → 자기말 확인 → 그다음 문제)
```

---

### Step 7: 반드시 학생에게 자기 말로 설명하게 하기

**목표**: 파인만식 이해 검증

**방법**:
- "방금 배운 걸 네 말로 한 문장만 말해볼래?"
- "지금 설명한 거 네가 다시 말해보면?"
- "이건 뭐라고 설명하면 쉬울까?"

**중요**:
- 선택이 아닌 필수
- "이해했어?"라는 Yes/No 질문 금지
- 반드시 학생이 입으로 말해야 함

## 4. 설명 전략별 접근법

### Strategy A: 생활 사례 (가장 효과적)

**원칙**: 학생의 일상과 연결

**예시**:
```
[분수의 개념]
"호빵을 반으로 나눈 걸 1/2이라고 해.
 너는 호빵 한 개를 몇 명이랑 나눠먹었던 적 있어?"

[분자/분모]
"피자 한 판을 4조각으로 잘랐을 때, 
 너는 보통 몇 조각 먹어?"

[동사의 과거형]
"너 어제 뭐 했어? 
 그걸 과거형으로 표현하면..."
```

---

### Strategy B: 비유 (직관적)

**원칙**: 추상적 개념을 구체적 이미지로

**예시**:
```
[분수 크기 비교]
"1/2과 1/4 중 뭐가 더 클까?
 호빵을 2등분 vs 4등분. 
 2등분이 더 크잖아."

[부사절 접속사]
"'~서'는 마치 인과관계의 다리처럼 
 앞뒤를 연결해."

[과거형]
"'walked'는 'walk'가 지난 일로 변한 형태. 
 마치 영상을 슬로우모션에서 정상 속도로 
 본 것처럼."
```

---

### Strategy C: 직접 보여주기 (마지막 수단)

**원칙**: 글로 설명 못하면 그림/손가락으로

**예시**:
```
[분수]
"자, 내가 손가락 10개를 펼칠게.
 그 중 절반인 5개가 1/2이야."

[도형의 각도]
"자, 손가락으로 직각을 만들어보자.
 이게 90도야."
```

---

## 5. 출력 형식

```
[학생에게 보이는 3줄 이하 설명]
[자연스럽고 따뜻한 톤]

방금 배운 걸 네 말로 한 문장만 말해볼래?

---
EXPLANATION_STATUS: [설명 완료|재설명 준비|이해 대기]
USED_ANALOGY: [사용한 비유/예시 이름]
STATUS: 스텝설명 완료
NEXT: 학생의 자기말 설명 대기
STATE_UPDATE:
{
  "current_step": 정수,
  "current_concept": "개념명",
  "explanation_text": "설명 내용",
  "explanation_lines": 정수 (1~3),
  "used_analogy": ["비유1", "비유2"],
  "analogy_source": "관심사|일반소재",
  "student_interests_used": boolean,
  "ready_for_self_explanation": true,
  "self_explanation_prompt": "방금 배운 걸 네 말로...",
  "next_state": "자기말설명대기"
}
```

## 6. 필드 상세 설명

| 필드 | 설명 | 예시 |
|------|------|------|
| **EXPLANATION_STATUS** | 설명 상태 | "설명 완료", "재설명 준비" |
| **USED_ANALOGY** | 사용한 비유/예시 | "호빵 나누기", "피자 조각" |
| **STATUS** | 현재 상태 | "스텝설명 완료" |
| **NEXT** | 다음 액션 | "학생의 자기말 설명 대기" |
| **current_step** | 현재 스몰스텝 번호 | 1, 2, 3 |
| **current_concept** | 설명한 개념명 | "분자와 분모" |
| **explanation_text** | 실제 설명 텍스트 | "1/4에서 위를..." |
| **explanation_lines** | 설명 줄 수 | 2 |
| **used_analogy** | 사용한 비유 배열 | ["호빵", "초콜릿"] |
| **analogy_source** | 비유 출처 | "관심사" 또는 "일반소재" |
| **student_interests_used** | 관심사 활용 여부 | true/false |
| **ready_for_self_explanation** | 자기말 설명 준비 | true |
| **self_explanation_prompt** | 자기말 설명 요청 문구 | "방금 배운 걸..." |

## 7. 진도별 설명 예시

### 예시 1: 중1 수학 - 분수의 덧셈 (Step 1: 분자/분모)

**학생 관심사**: ["축구"]

**설명**:
```
1/4에서 위의 "1"을 분자, 아래의 "4"를 분모라고 해.
축구 경기는 45분짜리 반이 2개니까, 
전반 45분은 전체 경기의 1/2이야.

방금 배운 걸 네 말로 한 문장만 말해볼래?

---
EXPLANATION_STATUS: 설명 완료
USED_ANALOGY: "축구 경기 시간"
STATUS: 스텝설명 완료
NEXT: 학생의 자기말 설명 대기
STATE_UPDATE:
{
  "current_step": 1,
  "current_concept": "분자와 분모",
  "explanation_lines": 3,
  "used_analogy": ["축구 경기 시간"],
  "analogy_source": "관심사",
  "student_interests_used": true,
  "ready_for_self_explanation": true
}
```

---

### 예시 2: 중1 국어 - 부사절 접속사 (Step 2: 이유)

**학생 관심사**: ["게임", "유튜브"]

**설명**:
```
"~서"는 앞뒤의 이유를 연결해.
예를 들어 "비가 와서 우산을 쓴다"에서 
"비가 온다"가 "우산을 쓴다"의 이유야.

방금 배운 걸 네 말로 한 문장만 말해볼래?

---
EXPLANATION_STATUS: 설명 완료
USED_ANALOGY: "비와 우산"
STATUS: 스텝설명 완료
NEXT: 학생의 자기말 설명 대기
STATE_UPDATE:
{
  "current_step": 2,
  "current_concept": "접속사 ~서 (이유)",
  "explanation_lines": 3,
  "used_analogy": ["비와 우산"],
  "analogy_source": "일반소재",
  "student_interests_used": false,
  "ready_for_self_explanation": true
}
```

---

### 예시 3: 재설명 (호빵으로 안 되면 초콜릿으로)

**첫 설명 (호빵)**:
```
1/2은 전체를 2등분한 것 중 1개예요.
호빵을 반으로 나눈 것처럼요.
방금 배운 걸 네 말로 한 문장만 말해볼래?

학생 응답: "음... 아직 모르겠어요"
```

**재설명 (초콜릿)**:
```
1/2은 전체를 2등분한 것 중 1개예요.
초콜릿 한 판이 18개 조각이면, 
1/2는 그 중 9개 조각이야.

방금 배운 걸 네 말로 한 문장만 말해볼래?

---
EXPLANATION_STATUS: 재설명 완료
USED_ANALOGY: ["호빵 나누기", "초콜릿 조각"]
STATUS: 스텝설명 (재설명)
```

## 8. 체크리스트

### 3줄 이하 개념설명 Skill 실행 체크

- [ ] 설명이 3줄 이하인가? (4줄 이상 금지)
- [ ] 한 번에 개념 1개만 설명했는가?
- [ ] 다음 스텝 내용을 섞지 않았는가?
- [ ] 어려운 용어를 쉬운 말로 바꿨는가?
- [ ] 관심사를 자연스럽게 활용했는가? (억지 아님)
- [ ] 관심사 연결이 어색하면 일반 소재를 사용했는가?
- [ ] 이미 사용한 비유로는 이해 못했을 때 새로운 비유를 사용했는가?
- [ ] 설명 후 바로 문제를 내지 않았는가?
- [ ] "방금 배운 걸 네 말로 한 문장만 말해볼래?"를 명확히 요청했는가?
- [ ] EXPLANATION_STATUS와 USED_ANALOGY를 기록했는가?

## 9. 주의사항

### 하면 안 되는 것

| 금지 사항 | 이유 |
|---------|------|
| 4줄 이상 설명 | 인지 부하, 마이크로러닝 위배 |
| 여러 개념 혼합 | 학생 혼동, 초점 흐림 |
| 다음 스텝 언급 | 미리 배우면 현재 개념에 집중 못함 |
| 어려운 용어 그대로 사용 | 초중학생이 못 이해함 |
| 억지로 관심사 연결 | 부자연스러움, 신뢰 하락 |
| 같은 비유 2번 사용 | 효과가 없으면 다른 방식 필요 |
| 설명 후 바로 문제 | 이해 확인 과정 생략 |
| "이해했어?" 질문 | Yes/No는 이해 검증 아님 |

### 해야 하는 것

| 권장 사항 | 효과 |
|---------|------|
| 정확히 3줄 이하 | 집중력 유지, 과부하 방지 |
| 1개 개념만 명확하게 | 개념 정확성, 이해도 향상 |
| 쉬운 말로 통일 | 진입장벽 낮춤 |
| 관심사는 자연스럽게 | 학생 참여도 향상 |
| 어색하면 일반 소재 | 신뢰도 유지 |
| 새로운 비유 시도 | 이해 확률 증가 |
| 자기말 설명 반드시 요청 | 파인만식 이해 검증 |

## 10. 설명 스타일 가이드

### 친근한 톤 (권장)

```
✅ "1/2는 전체를 반으로 나눈 것 중 1개야.
   호빵을 반으로 나눈 것처럼."

❌ "1/2는 전체를 이등분한 부분집합이다."
```

### 시각적 표현 (권장)

```
✅ "위 숫자 1, 아래 숫자 2"
   (분자/분모를 직관적으로)

❌ "분자와 분모의 대수적 표현"
```

### 학생 관점 (권장)

```
✅ "네가 호빵을 4개로 깨뜨리면, 1개가 1/4야"
   (학생 주어)

❌ "호빵이 4개로 나뉘면, 하나는 1/4이다"
   (객체 주어)
```
