# Skill: 주간 총괄 복습 문제집

## 1. 스킬 정의

### 이름
주간 총괄 복습 문제집

### 역할
**한 주간(월~금 또는 특정 기간) 복습한 모든 과목의 내용을 종합**하여, **시험이 아닌 "정리" 느낌으로 되짚게 하는** 스킬

### 활용 시점
- 금요일 세션 종료 후
- 사용자가 "주간 정리", "주간 복습" 요청했을 때
- 지정된 주간(월-금) 모든 세션 완료 후

### 입력값
- 한 주간의 모든 세션 기록
- 완료 스텝, 부분통과 스텝, 미완료 스텝 목록
- 각 개념별 반복 횟수
- 약한 개념, 강한 개념 분류

### 출력값
- **주간 정리 문제집**: 시험이 아닌 복습 느낌
- 과목별로 구성된 문제들
- 격려 메시지와 다음 주 안내

---

## 2. 핵심 원칙

| 원칙 | 설명 | 위반 예시 |
|------|------|---------|
| **정리 느낌** | 시험 아님 | ❌ "주간 시험" |
| **반복도 반영** | 약한 개념 더 출제 | ✅ 반복 3회 개념은 2문제 |
| **난이도 조절** | 갑자기 올리지 않기 | ❌ 선택지 1번에 초급, 2번에 고급 |
| **표현 자제** | "시험", "점수", "성적" 금지 | ✅ "정리", "모아보기", "확인" |
| **격려 중심** | 성취 강조 | ✅ "이번 주 잘했어" |
| **선택지** | 혼동 가능한 선택지만 | ✅ 3~4개, 모두 그럴듯한 것 |

---

## 3. 절차 (Step-by-Step)

### Step 1: 주간이력에서 스텝 데이터를 가져온다

**목표**: 한 주간 모든 세션의 진행 현황 파악

**조회 내용**:
```
주간 기간: 월(07-01) ~ 금(07-05)

세션 1 (월): 중1 수학 분수의 덧셈
- 완료: Step 1, 2, 3, 4
- 부분: (없음)
- 미완료: (없음)

세션 2 (화): 중1 국어 부사절 접속사
- 완료: Step 1, 2
- 부분: Step 3 (2회 반복)
- 미완료: (없음)

세션 3 (수): 중1 영어 과거형
- 완료: Step 1, 2
- 부분: Step 3 (1회 반복)
- 미완료: Step 4, 5

...

종합:
- 총 완료 스텝: 9개
- 총 부분통과: 2개
- 총 미완료: 2개
```

---

### Step 2: 반복이 많았던 개념은 1~2문제 출제한다

**목표**: 약한 부분 강화

**기준**:

| 반복 횟수 | 출제 문제 수 |
|----------|-----------|
| 3회 이상 | 2문제 |
| 2회 | 1~2문제 (선택) |
| 1회 (부분통과) | 1문제 |
| 완료 (반복 없음) | 0문제 (또는 1문제) |

**예시**:
```
주간 이력:
- 분수 개념: 1회 반복 → 1문제
- 분자/분모: 2회 반복 → 1~2문제
- 접속사 ~서: 3회 반복 → 2문제
- 과거형: 1회 반복 → 1문제

총 6~8문제 구성
```

---

### Step 3: 수월했던 개념은 1문제만 출제한다

**목표**: 완료된 개념은 가볍게 확인

**기준**:

| 완료 유형 | 출제 여부 | 문제 수 |
|----------|----------|--------|
| 1회 만에 완료 | 0문제 (생략) | 0 |
| 1회 만에 완료 (중요) | 1문제 (선택) | 1 |
| 부분통과 | 1문제 | 1 |
| 여러 번 후 완료 | 1~2문제 | 1~2 |

**예시**:
```
강한 개념 (생략 가능):
- 분수 개념 (1회만에 완료)
- 분모 이해 (완료)
- 과거형 규칙 (1회만에 완료)

약한 개념 (출제):
- 분자와 분모 (2회 후 완료) → 1문제
- 접속사 종합 (3회 후 완료) → 2문제
```

---

### Step 4: 난이도를 갑자기 올리지 않는다

**목표**: 정리 느낌 유지, 새로운 어려움 추가 금지

**금지**:
```
❌ 월에 배운 쉬운 개념 → 금에 출제할 때 극어려운 버전
❌ 선택지에서 갑자기 고급 개념 포함
❌ "이번 주 복습이니까 고등학교 수준으로"
```

**올바른 방법**:
```
✅ 월의 난이도와 비슷한 수준 유지
✅ 다만 "복합 적용" 정도는 가능
   예: "분수 개념"은 선택지만 제시하고,
       "분자/분모"는 계산까지 요구 가능
```

**예시**:
```
월: 분수 개념 (선택지형, 쉬움)
금: 분수 덧셈 규칙 (계산, 좀 더 어려움)

△ 금에 분수 개념 재출제 시:
   월 수준: "1/2과 1/4 중 큰 건?"
   금 수준: "1/2과 1/3과 1/4를 크기순 정렬"
   (약간 상향, 하지만 극단적이지 않음)
```

---

### Step 5: "시험", "점수", "성적"이라는 표현을 쓰지 않는다

**금지 표현**:
```
❌ "주간 시험"
❌ "점수를 내보자"
❌ "주간 성적"
❌ "채점하자"
❌ "통과선 80점"
❌ "등급"
```

**대체 표현**:

| 금지 | 대체 |
|-----|------|
| 시험 | 정리, 복습, 모아보기 |
| 점수 | 개수, 문제 풀이 |
| 성적 | 이해도, 진행 현황 |
| 채점 | 확인, 함께 봐보자 |
| 통과선 | (제시 X, 대신 격려) |
| 등급 | (사용 X) |

---

### Step 6: "이번 주 정리", "모아보기", "다시 확인"이라는 표현을 사용한다

**권장 표현**:

| 상황 | 표현 |
|------|------|
| 제목 | "이번 주 정리", "주간 모아보기" |
| 시작 | "이번 주 배운 걸 한 번 더 봐보자" |
| 설명 | "다시 한 번 확인해보자" |
| 종료 | "이번 주 정말 잘했어" |

**예시**:
```
✅ "이번 주 정리: 분수와 접속사"
✅ "이번 주 배운 것들을 모아보자"
✅ "지난주 복습하면서 다시 확인해보자"
❌ "주간 시험 시작합니다"
```

## 6. 과목별 문제 구성 예시

### 예시 1: 수학 (분수의 덧셈)

```

- Step 3: 같은 분모 (완료, 1회)
- Step 4: 덧셈 규칙 (완료, 1회)

[출제 계획]
- 분수 개념: 생략 (완료, 반복 없음)
- 분자/분모: 1~2문제 (2회 반복)
- 같은 분모: 1문제 (부분통과)

총 3~4문제

[생성된 문제]
Q1. 1/2과 1/3을 더하려면, 
    먼저 뭘 해야 할까?
    ① 분자끼리 더하기
    ② 분모를 같게 하기 (정답)
    ③ 크기를 비교하기

Q2. 1/2와 1/4의 분모를 같게 하려면?
    ① 2로 통일
    ② 4로 통일 (정답)
    ③ 8로 통일

Q3. 1/4 + 1/4 = ?
    ① 1/2 (정답)
    ② 2/8
    ③ 1/8
```

## 7. 체크리스트

### 주간 총괄 복습 문제집 생성 체크

- [ ] 한 주간(월~금) 모든 세션 데이터를 수집했는가?
- [ ] 완료/부분/미완료 스텝을 구분했는가?
- [ ] 반복 횟수에 따라 출제 문제 수를 조정했는가?
  - [ ] 3회 이상 반복: 2문제
  - [ ] 2회 반복: 1~2문제
  - [ ] 1회 반복/부분통과: 1문제
  - [ ] 완료(반복 없음): 0~1문제
- [ ] 난이도가 월~금 수준과 비슷한가? (갑자기 올리지 않음)
- [ ] "시험", "점수", "성적" 표현 없는가?
- [ ] "정리", "모아보기", "다시 확인" 표현 사용했는가?
- [ ] 격려 메시지가 있는가?
- [ ] 마지막에 다음 주 안내가 있는가?
- [ ] 과목별로 명확히 구분했는가?

## 8. 주의사항

### 하면 안 되는 것

| 금지 사항 | 이유 |
|---------|------|
| "시험" 표현 | 부담감, 긴장 ↑ |
| 난이도 급상향 | 학생 좌절감 |
| 점수/등급 제시 | 비교/평가 중심 |
| 미완료 강조 | 실패감 |
| 선택지 너무 유사 | 혼동 증가 |
| 새로운 개념 포함 | 정리가 아님 |

### 해야 하는 것

| 권장 사항 | 효과 |
|---------|------|
| "정리" 표현 | 편안함, 복습 느낌 |
| 난이도 일정 | 자신감 유지 |
| 성취감 강조 | 동기 ↑ |
| 완료 먼저 | 격려 느낌 |
| 명확한 선택지 | 판단 용이 |
| 배운 것만 | 정리 완성 |

## 9. 난이도 분포 가이드

총 6~8문제 기준:

```
쉬움 (1~2문제): 선택지 1~2개 포함하면 분명한 수준
중간 (3~4문제): 생각해야 하지만 배운 수준
어려움 (1~2문제): 최대 2개 (선택사항)

비율: 약 1:2:1 또는 1:3:0
```

## 11. 주간정리 vs 일일리포트

```
일일리포트:
- 그날 배운 내용 정리
- 학생용/교사용 분화
- 점수 없음, 성취감 강조

주간정리:
- 한 주간 배운 내용 모아보기
- 약한 부분 집중 복습
- 문제집 형식 (풀어보기)
- 시험이 아닌 정리 느낌
```
